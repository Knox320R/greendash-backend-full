Specification Document — New
GreenDash System
1. General Operation
● Users purchase EGD token packages using USDT (Binance Smart Chain).
● Each package has a maximum earning cap of 300% of the purchased value.
● All payments (daily rewards and commissions) are made in EGD.
● Daily rewards and commissions can be converted to USDT at any time and
withdrawn instantly.
2. Clear Rules
1. 300% Cap — TOTAL TOKENS RECEIVED
○ The 300% cap represents the total amount of EGD tokens a user will receive
during the package’s validity.
○ Once the cap is reached, the package automatically expires, and the user
must purchase another to continue earning.
○ Example:
■ Package of $100 = 10,000 EGD
■ Cap of 300% = $300 = 30,000 EGD
■ As soon as the user has received 30,000 EGD (sum of daily rewards
and commissions), the package ends.
2. Only Active Package Holders Earn Commissions
○ If a user does not have an active package, they will not receive any
commission.
○ Applies to both paid and free packages.
3. Mandatory Repurchase
○ When 300% of the invested value (in tokens) is reached, the package
expires.
○ To keep earning rewards and commissions, the user must buy a new
package.
4. Package Purchases
○ Exclusively in USDT (BEP-20).
○ Automatic conversion to EGD at purchase.
○ 1 USDT = 100 EGD (adjust according to real token price).
5. One Active Package at a Time
○ Each user can only have 1 active package.
○ Upgrades are allowed (replacing the current package with a bigger one).
6. Token Lock & Gradual Release
○ Users do not receive all tokens at once upon purchase.
○ Tokens are released gradually through daily rewards and commissions, until
the cap is reached.
○ Once the 300% cap in tokens is reached, the package expires.
3. Conversion & Withdrawal
● Earnings are always paid in EGD.
● Users can convert any amount of EGD to USDT inside the system at any time.
● After conversion, withdrawals can be made instantly.
4. Practical Examples
Example 1 — Daily Rewards
● Package of $1,000 → 100,000 EGD
● Cap of 300% = $3,000 → 300,000 EGD
● Daily reward: 1.5% = 1,500 EGD/day
● After ~200 days (example), the cap is reached, and the package ends.
Example 2 — Direct Commission
● Package of $1,000 → 100,000 EGD
● Cap of 300% = $3,000 → 300,000 EGD
● Direct sale of a $10,000 package = 15% commission → $1,500 = 150,000 EGD
● Remaining available earnings: $1,500 = 150,000 EGD
● One single sale already consumed 50% of the possible cap for this package.
5. Quick Implementation Summary
● 300% cap = total EGD tokens received (daily rewards + commissions).
● 1 active package at a time (paid or free).
● Mandatory repurchase when the 300% cap in tokens is reached.
● All payments in EGD, with instant conversion to USDT and immediate withdrawals.
● Purchases only with USDT BEP-20.
● Tokens released gradually until the 300% cap is reached.
